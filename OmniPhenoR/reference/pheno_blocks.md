# Show the OmniPhenoR implementation blocks

Version 1.0.0 consolidates 240 implementation blocks across five
development generations: classical phenotyping (0.1.0), R-native deep
learning (0.2.0), external computer-vision interoperability (0.3.0),
longitudinal phenotyping (0.4.0), and experiment/data infrastructure
with MIAPPE, BrAPI, FAIR, provenance, and portable research bundles
(0.5.0).

## Usage

``` r
pheno_blocks(pattern = NULL)
```

## Arguments

- pattern:

  Optional regular expression applied to module and function.

## Value

A tibble describing the implementation registry.
