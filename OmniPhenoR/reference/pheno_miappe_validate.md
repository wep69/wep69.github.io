# Validate core MIAPPE-aligned metadata

Validate core MIAPPE-aligned metadata

## Usage

``` r
pheno_miappe_validate(experiment, strict = FALSE)
```

## Arguments

- experiment:

  `pheno_experiment`.

- strict:

  If `TRUE`, recommended missing fields also make overall status
  incomplete.

## Value

List with field diagnostics and summary.
