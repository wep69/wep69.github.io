# Join phenotype observations with environmental records

Join phenotype observations with environmental records

## Usage

``` r
pheno_weather_join(
  phenotypes,
  weather,
  pheno_time,
  weather_time,
  by = NULL,
  method = c("exact", "nearest"),
  tolerance = Inf
)
```

## Arguments

- phenotypes:

  Phenotype data frame.

- weather:

  Environmental/weather data frame.

- pheno_time:

  Phenotype time column.

- weather_time:

  Weather time column.

- by:

  Additional exact join keys, such as environment.

- method:

  `"exact"` or `"nearest"`.

- tolerance:

  Maximum nearest-time difference; `Inf` by default.

## Value

Joined data frame with weather columns.
