# Functional principal components of phenotype trajectories

Functional principal components of phenotype trajectories

## Usage

``` r
pheno_fpca(x, ncomp = 3L, center = TRUE, scale. = FALSE)
```

## Arguments

- x:

  A `pheno_functional` object.

- ncomp:

  Number of components to retain.

- center:

  Center trajectories.

- scale.:

  Scale grid columns before PCA.

## Value

A `pheno_fpca` object containing scores, loadings and explained
variance.

## References

Yao F, Mueller HG, Wang JL (2005). JASA 100:577-590.
[doi:10.1198/016214504000001745](https://doi.org/10.1198/016214504000001745)
.
