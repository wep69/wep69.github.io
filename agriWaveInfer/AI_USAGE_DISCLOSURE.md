suggestions, test-design scaffolds, documentation drafting,
release-manifest preparation, and bibliographic/metadata reconciliation
during development. Scientific scope, package architecture,
causal-interpretation boundaries, acceptance of code changes, release
decisions, and final responsibility remain with the human authors.

Before journal submission, this disclosure must be reconciled with the
exact public repository history, exact tools/models used in the
submitted development record, human review/validation performed, and the
target journal policy. Runtime results must not be attributed to
AI-generated predictions; they must come from executed software and
preserved validation evidence.
