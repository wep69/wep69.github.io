# State of the art — scientific software publication layer

Version 1.0.0 treats software provenance, machine-readable citation
metadata, validation evidence, and reproducibility artifacts as part of
the scientific product rather than administrative extras. FAIR4RS
emphasizes versioned identifiers, rich metadata, provenance, clear
licensing, qualified references, interoperability, and reusable
documentation. Citation File Format provides machine-readable citation
metadata, while CodeMeta supports cross-system software metadata.

The current JOSS guidance (checked 2026-09-05) requires a short Markdown
paper with Summary, Statement of need, State of the field, Software
design, Research impact statement, AI usage disclosure,
acknowledgements, and references. JOSS also states that private
development alone is not sufficient for submission: a public
open-development record is expected. Therefore 1.0.0 prepares, but does
not claim, submission readiness.
