# Roadmap — agriWaveInfer 0.1.0 to 1.0.0

## Completed development line

- **0.1.0** Foundations and unified wavelet layer.
- **0.2.0** Conditional and multivariate inference.
- **0.3.0** Null models and field-aware inference.
- **0.4.0** Driver attribution and parsimonious selection.
- **0.5.0** Phase, multiscale lead-lag and predictive direction.
- **0.6.0** Agronomic semantics and propagation.
- **0.7.0** Time-frequency networks.
- **0.8.0** Spatial inference and scalability.
- **0.9.0** Scientific validation and publication layer.
- **1.0.0** Consolidated Scientific Release: API freeze, release
  metadata reconciliation, golden-reference consolidation, final source
  audit and release archives.

## 1.0.0 principle

No new methodological domain was introduced at 1.0.0. The release
consolidates and freezes the existing public surface. Runtime
certification remains evidence-dependent and must be completed on the
exact release archive.

## Post-1.0 development

Future 1.x releases should prioritize runtime certification evidence,
performance improvements, additional differential oracles, documented
migrations, richer diagnostics, and optional extensions without breaking
the 1.0 contracts. Major causal-inference, deep-learning,
learnable-wavelet, or graph-neural-network domains should not be
inserted casually into the 1.x core.
