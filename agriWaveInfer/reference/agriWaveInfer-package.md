# agriWaveInfer: Multiscale Statistical Inference for Agroclimatic Systems

Scientific data contracts, unified CWT/XWT/WTC, improved partial and
multiple wavelet coherence, surrogate null models, field-aware
time-frequency inference, driver attribution, circular lead-lag
analysis, phenology-aware stage summaries, and ordered noncausal
propagation workflows for agroclimatic and environmental systems.
