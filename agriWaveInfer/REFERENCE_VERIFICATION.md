# Reference verification — agriWaveInfer 1.0.0

The consolidated 1.0.0 bibliography inherits the verified methodological
corpus from 0.9.0. BibTeX and RIS DOI sets are reconciled again during
the final static audit. No author, title, journal, DOI, page range, or
publication year should be added without independent verification.

# Reference verification — agriWaveInfer 1.0.0

Bibliographic metadata inherited from 0.8.0 is retained. Version 1.0.0
adds FAIR4RS (Barker et al. 2022; DOI 10.1038/s41597-022-01710-x) and
the Software Citation Principles (Smith et al. 2016; DOI
10.7717/peerj-cs.86). Both DOIs were verified against publisher or
project documentation during the 1.0.0 build.

JOSS requirements are treated as time-sensitive web guidance rather than
static bibliographic references and must be rechecked immediately before
any submission.
